## 1. 项目概况

War Thunder「击中分析」复刻原型：以物理公式 + 数据表驱动的方式，复刻 War Thunder 的弹道、穿透判定与后效（破片锥 / 超压 / 连锁反应）机制，并提供 2D X 光图与 3D 场景（Three.js）双轨可视化、命中回放与战斗记录持久化。

| 维度     | 现状                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 前端     | React 18 + Vite 5 + TypeScript + Zustand 4 + Three.js（@react-three/fiber 8 / drei 9）        |
| 后端     | Express 4 + Prisma 5 + SQLite（可切换 PostgreSQL）+ Zod 4 入参验证                            |
| 工程化   | npm 统一包管理、husky + lint-staged、ESLint 9 + Prettier、GitHub Actions CI                   |
| 代码规模 | 前后端 src 合计约 24.3 万字节（最大文件 HitEffects.tsx 588 行 / penetration.ts 666 行含注释） |
| 测试     | 4 个测试文件、111 个用例全绿（约 2 秒）；后端无测试                                           |
| 数据     | 5 种弹种（AP/APHE/APCR/HEAT/HE）、1 辆 3D 载具（T-72B3，17 个分区碰撞体）                     |

## 2. 架构评估（结论：分层健康，纪律执行到位）

```
frontend/src/
├── data/         # 弹药参数、载具装甲分区、3D 碰撞体（纯数据）
├── lib/          # 弹道 / 穿深 / 后效 / 连锁反应（纯函数，零 React 依赖）✔
├── store/        # Zustand 唯一战斗状态源 ✔
├── api/          # 后端调用，失败回退 localStorage ✔
├── components/   # 2D UI（保留为降级路径）
└── components3d/ # React Three Fiber 3D 渲染层
backend/          # Express 路由 + Zod schema 验证 + Prisma
```

**验证通过的架构优点：**

1. **物理计算与渲染完全解耦**：`lib/` 下 4 个模块（ballistics / penetration / chainReactions / HitSimulator）均为纯函数，测试可直接覆盖，这是 111 个用例能稳定在 2 秒内跑完的根本原因。
2. **后效策略模式落地良好**：`POST_EFFECT_STRATEGIES` 注册表 + 5 个弹种策略类，新增弹种只需「data 加数据 + 注册表加一行」，扩展成本极低。
3. **坐标系纪律有显式护栏**：弹道坐标系（x前/y右/z上）与 Three.js 坐标系（x右/y上/z前）的转换被约束在渲染边界，且 3D 直线命中结果带 `coordSpace: 'three'` 打标，防止历史遗留的坐标混淆缺陷复发。
4. **载具状态机有优先级仲裁**：`STATE_PRIORITY` 常量保证状态只升不降（如 `ammo_detonated` 不会被后续 `module_damaged` 覆盖），避免了连锁反应乱序。
5. **后端入参防御完备**：Zod schema 覆盖全部写接口，PATCH 使用 `.strict()` 白名单，生产环境错误信息脱敏（`safeError`）。

## 6. 总体结论

这是一个**架构纪律执行良好、核心物理层质量高于一般原型水平**的项目：纯函数 lib 层 + 策略模式 + 111 个单元测试构成了坚实的可演进底座。当前的主要债务不在"设计错误"，而在**工程闭环不完整**（后端无测试、概率不可重现、双数据源分叉）与**单载具硬编码导致的扩展瓶颈**。建议按《优化迭代报告》分三期推进：第一期补工程闭环，第二期突破扩展瓶颈，第三期做架构演进与体验升级。
