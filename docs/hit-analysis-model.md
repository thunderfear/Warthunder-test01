# 击中分析效果实现说明（建模与公式文档）

本文档说明《战争雷霆 · 击中分析复刻》中"命中效果"是如何计算出来的、依据哪些公式、以及每种弹药/装甲是否独立建模。

---

## 一、总览：公式 + 数据表的混合建模

命中效果**不是纯随机**，也**不是逐像素的有限元物理仿真**，而是：

> **公式负责"物理规则"，数据表负责"每种装备的差异化参数"。**

- 物理规则：弹道下落、有效装甲厚度（余弦斜率 + 转正）、穿透/跳弹判定、后效伤害逻辑 —— 这些都是确定性的数学公式。
- 差异化参数：每种弹药的穿深曲线、转正角、跳弹阈值、后效模型、弹道系数；每块装甲/模块的厚度、倾角、装甲类型 —— 都是可独立配置的数据表。

因此：**每种弹药、每块装甲都是"独立建模"的**（各自有参数），但判定过程由同一套公式驱动。这正是《战争雷霆》真实采用的思路的简化版。

---

## 二、弹道与入射角（`lib/ballistics.ts`）

一次命中由"交战距离 + 所选弹药"决定弹道俯角：

```
飞行时间   t        = d / v0                         （v0 = 初速，忽略阻力的一阶近似）
真空下落   drop₀    = ½ · g · t²                    （g = 9.81 m/s²）
阻力修正   drop     = drop₀ · clamp(1.4 − BC, 0.8, 1.3)   （BC = 弹道系数，越大下落越少）
入射角     φ        = atan(drop / d)                 （相对水平面的俯角，单位°）
```

最终入射角再加上装甲板自身的倾角 `slope`，得到命中点的真实入射角：

```
入射角 = φ + slope
```

**适用范围与局限（声明）**：该抛物线模型在 **0–1500m** 内误差约 **±3°**，足够演示。1500m 以上、或对 APHE/HE 低初速弹追求精度时，应引入**弹道系数积分**（按 `v0` 与 `BC` 做逐段阻力积分求下落量），本版预留该升级路径。

## 三、穿透 / 跳弹 / 后效（`lib/penetration.ts`）

### 1. 有效装甲厚度（余弦斜率定律 + 转正）

```
θ        = max(0, 入射角 − normalization)     （normalization = 弹种转正角，可"压平"入射角）
cosθ     = cos(θ)
有效厚度  effThk = nominalThickness / cosθ
```

- 倾角的意义：装甲越倾斜，`cosθ` 越小，有效厚度越大（例如 55° 倾角使 100mm 板等效约 174mm）。
- 转正的意义：AP/APHE 命中时把入射角压平几度，提升对倾斜甲的效果。

### 2. 穿透 / 跳弹判定

```
shellPen = penAt(ammo, distance)             （由弹种穿深曲线在距离 d 线性插值得到）
if HE(爆破弹):     命中即引爆，不依赖穿透
else if shellPen ≥ effThk:  击穿
else if 入射角 > ricochetThreshold:  跳弹
else:              未击穿（被弹开/吸收）
```

### 3. 装甲类型修正（差异化逻辑）

| 装甲类型 | 对 HEAT（破甲） | 对 AP/APCR/APHE（动能） |
|----------|----------------|------------------------|
| `RHA` 均质钢 | 正常 | 正常 |
| `spaced` 间隙 | 射流在间隙中扩散，后效 ×0.4 | 正常 |
| `composite` 复合 | 穿深 ×0.85 | 穿深 ×0.95 |
| `ERA` 反应装甲 | **完全引爆金属射流 → 失效**（不击穿） | 穿深 ×0.7（削减约 30%） |

### 4. 后效伤害（按弹种 `postPen` 模型）

- `direct`（AP）：命中模块/乘员直接损伤（乘员约 100%）。
- `spall`（APHE）：击穿后炸药产生额外破片，后效更高（模块约 90%）。
- `jet`（HEAT）：成型装药；命中 `spaced` 时间隙使后效大幅降低（×0.4）。
- `weak`（APCR）：穿深高但动能小，后效弱（乘员约 80%）。
- `blast`（HE）：不需击穿，命中即爆破；薄甲（≤30mm）产生破片杀伤内部乘员。

### 5. 边界与异常（已处理）

- **入射角接近 90°**（`cosθ < 0.01`，弹丸几乎平行于装甲表面）→ 直接判定跳弹/未击穿，避免 `effThk` 趋近无穷大。
- **命中载具之外**（点击空白处）→ 返回"未命中"，不报错。
- **同一模块被反复命中** → 在 `battleStore` 中按 `postPenDamage` 累加损伤（封顶 100%），可呈现"累计损毁"。
- **ERA 化解 HEAT** → 标记 `armorNeutralized`，不进入常规穿透判定。

## 四、弹药差异化建模（`data/ammo.ts`）

每种子弹有独立参数表（`penCurve` 为随距离变化的穿深数据表）：

| 弹种 | 穿深特征 | 转正 | 跳弹阈值 | 后效 |
|------|----------|------|----------|------|
| AP   | 随距离下降 | 0° | 70° | 直接 |
| APHE | 略低于 AP | 3° | 70° | 溅射(更高) |
| HEAT | 基本不随距离衰减 | 0° | 80° | 成型射流 |
| APCR | 高穿深、衰减快 | 0° | 70° | 弱后效 |
| HE   | 不依赖击穿 | — | — | 爆破/破片 |

## 五、装甲 / 模块差异化建模（`data/vehicle.ts`）

载具被划分为多个独立分区（侧视 X 光），每个分区独立建模：

```
{ key, label, category(armor|module|crew), armorType(RHA|spaced|composite|ERA),
  nominalThickness, slope, rect(渲染/点击区域) }
```

示例分区含：首上装甲、驾驶员、变速箱、弹药架、车体侧装甲、油箱、发动机、炮塔前/后装甲、炮闩、炮手、装填手、车长、指挥塔、火炮身管、履带等。每个分区有独立厚度、倾角与装甲类型。

> 首版交付**侧视** X 光；数据结构已预留 `viewAngle` 扩展，便于后续加入正视 / 俯视多角度。

## 六、结论：每种弹药/装甲是否独立建模？

**是。** 每种弹药有不同的穿深曲线、转正、阈值、后效模型；每块装甲有不同的厚度、倾角、装甲类型，并在穿透/后效逻辑中被差异化处理。但所有判定由同一套（上述）公式驱动。

即：**带公式的数据模拟（data-driven + analytical model）**，而非逐顶点有限元仿真。它在"可工程实现"与"物理可信度"之间取得了平衡，也是真实游戏采用的方式。

## 七、数据来源与免责声明

弹药穿深数据基于**公开军事资料（二战 88mm 级别火炮）估算**，**仅供游戏模拟参考**，不代表任何真实装备的精确参数。载具分区为示意性建模，非某特定型号的工程图纸。

## 八、可扩展路径

1. 弹道：用弹道系数积分替代抛物线近似，提升远距离精度。
2. 装甲：加入正/俯视多角度 `slope`，更精确反映命中角度。
3. 弹种：扩充至更多历史弹药并接入真实测准数据。
4. 可视化：如需真正 3D X 光，可引入 Three.js 几何体建模（工程量较大，属独立阶段）。
